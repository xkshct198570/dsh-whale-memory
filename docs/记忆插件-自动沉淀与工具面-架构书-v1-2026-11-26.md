## 3. 上游对比与取舍（Phant0Meow/dsh-meow-memory）

上游核心（MIT，README + 源码）：七层 `soul/user/project/fact/lesson/topic/rules`；首轮快照注入 + 每消息 top-2 关键词命中 + project 锚定 + 压缩后重注入；普通记忆**免审直写、写入即去重合并**；8 个 `memory_*` 工具 + `/dream`；反思在“任务结束、连续 ≥7 非 memory 工具步”触发；dream 空闲 180min、峰时 09–12/14–18 抑制、三轮整理；外部 `.dsh-meow` 信任门。

| 环节 | 上游 | 现役 0.7.3 | 取舍 |
|:--|:--|:--|:--|

## 4. 目标流程（收尾与主动写入）

```
采集/主动工具 ──► 价值闸（durable?） ──► 去歧义改写（≤200 字，无相对指代/主观前缀）
                        │否：审计 REJECT(task_instruction_not_memory / stale_version_fact)
                        ▼
                 kind 分流：rule → 规则提案（pending，人工审批）
                            open_loop → 报告待办（不落长期）
                            lesson/decision/preference/fact
                        ▼
             writer.decide（同身份）：同文 NOOP／相似 MERGE／冲突 SUPERSEDE／protected→REVIEW
                        ▼
        ADD/MERGE/SUPERSEDE → active + writes 审计（before/after）＋可选 evolution
        REVIEW → writes CANDIDATE（仅这类需面板审）
```

主动工具 `memory_remember` 走同一 writer 管道；`memory_search` 复用 search；`memory_update` 走 updateNode（保护面/CAS）；`memory_read` 只读。工具默认写当前身份（user/role/workspace），不允许跨分区参数。

## 5. 契约

### 5.1 配置（新增，默认按厂长口径）

```yaml
wrap:
  ingest:
    mode: auto            # auto | review；auto=普通记忆直接入库，review=旧行为
    minConfidence: 0.55   # 低于则 REVIEW
    reviewOnAmbiguity: true
    dropTaskInstructions: true
tools:
  enabled: true           # memory_* 工具总开关
  maxWritesPerTurn: 5
```

- `mode=auto` 仅对 `origin=session-wrap` 生效；其它来源仍受全局 `write.reviewMode` 控制。
- `kind=rule` 永不走 auto；`open_loop` 永不落长期。
- 全局 `wrap.autoAccept` 删除（被 ingest.mode 取代），旧值迁移。

### 5.2 工具契约（最小集）

| 工具 | 参数 | 返回 | 语义 |
|:--|:--|:--|:--|
| `memory_remember` | `{text, level?, memory_type?, tags?}` | `{ok, action, id?, reason}` | 走 writer auto；同文 NOOP/相似 MERGE/冲突 SUPERSEDE；保护面 REVIEW |
| `memory_search` | `{query, limit?}` | `{hits:[{id,text,level,score}]}` | 同身份 FTS+扩散；不返回原文以外内容 |
| `memory_read` | `{id}` | `{ok, node}` | 同身份；跨分区 404 |
| `memory_update` | `{id, text?, level?, tags?, expectedUpdatedAt?}` | `{ok, id}` | 保护面与 CAS 沿用面板 `updateNode` |
| `memory_forget`（可选） | `{id, reason}` | `{ok}` | 只 ARCHIVE，不物理删 |

工具不注册 `dream`；整理由 keeper/反思调度；工具调用写 `writes` 审计（source=tool，origin=tool）。

### 5.3 价值闸规则（可机械判定）

- 任务指令/要求句（“应该/需要/帮我/下个会话…”且无具体事实）→ `task_instruction_not_memory`。
- 版本状态/计数事实（“0.7.x 已装/测试 N 条”）→ `stale_version_fact`，不入长期；如需记录进报告。
- 相对指代（这次/刚才/上面/上次）或主观前缀（可能/大概/我觉得/应该）→ 尝试改写；改不了 → REVIEW。
- 同身份同 hash → NOOP；**同义改写也要判重**（token 集合 Jaccard ≥0.7 或关键词骨架相同 → MERGE/ARCHIVE 到 canonical）；字面相似 ≥0.85 且信息增益 → MERGE；冲突 → SUPERSEDE（保护面 → REVIEW）。实测 0.7.3 仅靠 hash/0.85 字面相似，6 条同义改写漏进（见施工计划 S1 夹具）。
- 置信度 < minConfidence → REVIEW。

### 5.4 数据与审计

- 不新增表；`writes` 已含 before/after/payload/mode/身份。ingest 写 `mode='auto'`、`origin='session-wrap'`/`tool`。
- schema v7（S3）：`nodes.layer TEXT NULL`（soul/user/project/fact/lesson/topic/rules，可空，旧行 NULL）；`nodes.project TEXT NULL`；迁移加法、幂等、迁移前备份。
- REVIEW 候选仍是 `writes.action='CANDIDATE'`，面板「写入与关系」可审；不新增队列。

## 6. 失败与可观测

- 自动入库失败（写库/事务）→ 条目 `write_failed:*`，run 失败可见，不静默；候选/报告计数体现。
- 价值闸/歧义闸命中 → `REJECT` + reason，报告列出计数，不写正文。
- UI 收尾卡增三行计数：`入库 N · 待审 M · 跳过 K`；CANDIDATE 页只显示 REVIEW。
- 日志：`wrap ingest added=N merged=N noop=N review=N rejected=N`（无正文）。

## 7. 测试策略（断言真实产物）

1. 自动入库：真库+假模型，3 durable → active；4 task → REJECT；重复 → NOOP 不新增行；相似 → MERGE 同 node；冲突 → SUPERSEDE 旧 active 变 superseded 且历史保留；protected → CANDIDATE。
2. 规则：rule 条目 → proposal pending，rules 文件零变化；apply 后才有文件。
3. 工具：真 ctx 注册 + 假模型调用 → nodes/writes 行；跨身份 id → 404；保护面 → REVIEW；CAS 冲突 → 409。
4. 面板：1280×800/900×700 渲染 + 六页签可点（0.7.3 回归保留）；候选计数与 DB 一致。
5. 故障注入：坏 JSON/超时/并发/跨身份/重复点击/重启（queue_cleared）；**同义改写/paraphrase 夹具**（token Jaccard ≥0.7）必须判重。
6. 门禁：`npm test`、check.mjs、build-client --check、check-deps、lint-size、compare-baseline、pack 644；基线全绿后刷新。

## 8. 风险与回退

| 风险 | 处置 |
|:--|:--|
| 自动入库膨胀/噪声 | 价值闸+去歧义+置信阈值；REVIEW 兜底；writes 审计可回滚（ARCHIVE/SUPERSEDE 不删行） |
| 错误合并覆盖好记忆 | 保护面强制 REVIEW；before/after 审计；相似阈值不变 |
| 工具越权/跨分区 | 工具只接受当前身份，拒绝身份参数；id 读取同分区校验 |
| 成本失控 | 工具按 turn 限次；反思/整理默认仍受 idle/峰时/每日上限；手动不受限 |
| schema v7 迁移 | 加法列、幂等、迁移前备份；旧代码忽略 NULL 列 |
| 回退 | `wrap.ingest.mode=review` 即回 0.7.3 行为；`tools.enabled=false`；schema 列保留不删 |
