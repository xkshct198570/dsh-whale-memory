## 0. 目标与非目标

**目标（本会话交付）**

1. **P1 远端读面收口**：`panel.allowRemote=true` 且非回环时，`GET /config`（含 `bots.*.private.bindings` 目标号）、
   `GET /persona`（人设全文）→ **403 `read_only_remote`**；`GET /personas` 保持 200 但**脱敏**（去目标号、去绝对路径）。
   回环行为不变。
2. **P2 保存回读语义**：`POST /config` 写盘成功后回读并校验关键字段；回读失败/不一致 → 仍 `ok:true` 且带
   `readBackFailed:true` + 短码原因；只有**写盘失败**才 501 `ok:false`。面板按此渲染（「已保存·回读失败」）。
3. **发布 0.5.4**：版本/CHANGELOG/DETAIL/README → `npm pack`（644、非 644=0）→ 隔离装载（合并后 `CASES=both`）→
   live 安装（`file:` 指 tarball）→ tag 推送触发 CI → Release 资产 sha 登记 → market（与鲸忆同一次提交）。
4. **两语齐全**：zh/en 键集一致、占位符一致；不引入 ja。

**非目标（延后清单）**：S3 资产状态位（`mirrorSynced` 可见）、S4 错误码→中文映射表、S5 `pick()`/资产读取缓存、
多主体批量/群白名单/A/B、面板信息架构、与鲸忆 shared-drift 全量收敛、与 Python 网关新联调、persona 与鲸忆的双装深水区
（隔离装 `CASES=both` 只做冒烟）。

## 3. 契约（r2 钉死，只留本轮范围）

1. **远端读面**：`allowRemote=true` 且非回环 → `/config`(GET)、`/persona`(GET) 403 `read_only_remote`；
   写面本就 403；`/personas` 脱敏后 200；`/resolve` 保留（无正文）。回环不变。
2. **脱敏**：远端 `/personas` 去 `bindings` 目标号（保留 `bound:boolean`）、去绝对路径（只留 key/显示名/来源/头像有无）。
3. **保存语义**：`commitConfig` 成功 → 回读 `config.json` 校验 `dsh/bots` 关键字段 → 失败仍 `ok:true` +
   `readBackFailed:true` + `readBackReason`（短码）；写盘失败 → 501 `ok:false`。**不得**把成功报成失败。
4. **文案**：zh/en 两语；`read_only_remote` 走既有码/`[code]`，不新建码表。
5. **不变项**：`config.json` 形状（Python 网关直读）、`persona-hub:persona` 名称/order=10、`whaleMemory` seam 形状。
6. **执行形态**：改在 worktree `~/dsh-persona-hub-wt`（分支 `closeout-0.5.4`）；门禁绿后主代理 `merge --ff-only` 回 main，
   再统一隔离/安装/发布；**禁止在 live `link:` 工作树直接改并 rebuild**。
