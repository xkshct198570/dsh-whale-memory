1. **对话自动召回**：每轮对话前检索本地长期记忆，按意图预算注入（闲聊 3 条 / 排障 5 条 / 回忆 4 条 / 画图 0 条）；2 秒超时即跳过，不卡回复。
2. **本地长期库**：记忆节点带层级、类型、双时态与工作区隔离，默认存本机 SQLite（`$DSH_HOME/whale-memory/memory.db`），不依赖外部服务。
3. **六页签面板**：概览（召回率/采纳率/作业成功率/7 日曲线）、记忆库（检索/编辑/归档/导入导出）、召回、写入与关系（审计/候选审核/演化）、规则（铁律/候选/历史/回滚/Git 状态）、设置（按场景分组的开关与导出）。
4. **写入可控**：单条 ≤500 字；默认 shadow 复核，候选经面板接受后才入库；JSONL 导入导出，改动留审计。
5. **规则可版本化**：铁律以 `~/.dsh/rules/` 的 Markdown 文件为真源，git 自动提交/回滚；冲突合并需用户确认；数据库只做检索镜像。
6. **旧库可迁移**：附 `migrate-audit` 脚本，只读对账、备份后迁移关系边，操作见 `docs/MIGRATION.md`。

隐私：默认数据只在本机；仅当手动把后端配成 http/hybrid 时，才向所填 url 发 stats/recent/search/recall/write/version 请求；不写遥测、不外传。
