## 1. 鲸忆（dsh-whale-memory）

### 1.1 语义召回（embed）——**已封存**，恢复时照这里接线

**现在是什么状态（2026-11-27 封存）**：代码层封存，不是死代码、不是半成品"待修"。

- **UI**：设置页不渲染 `embed` 组；概览不显示「待处理（vector_pending）」健康位；三语文案保留。
- **运行时零算力**：`vector` keeper job 是常量 stub（恒 `skipped:'shelved'`，不查库、不改状态、不读配置）；
  `/stats` 不再全表扫 `vector_pending`；写入路径恒 `vector_state='none'`。
- **数据面保留**：`config.embed`（enabled/endpoint/model/batch）、`nodes.embedding`（BLOB）、`nodes.vector_state`。
- **代码标记**：全仓 `grep -rn "SHELVED" src lib/client-src` 即得全部触点（配置/schema/守护/指标/导入导出/设置页）。
- **扫到这些代码的 agent**：直接跳过，不要"顺手清理/补实现/加回面板"。

**设计目的（供恢复时判断值不值得做）**：语义召回＝把文本交给 embedding 模型变成向量，
让「换了说法但意思一样」的记忆也能被想起（例：存「门禁失败不得发布」，问「上线前要跑测试吗」）。
**不是**网关/远程数据库：`embed.endpoint` 是 embedding 模型服务地址（如本机 Ollama `/api/embeddings`
或 OpenAI `/v1/embeddings`），向量存本机 SQLite 那两列。网关相关的是 `sync` 与 `backend.mode`，与 embed 无关。

**恢复前置**：
1. 本机 Ollama（宿主 `172.28.64.1:11434`）拉一个 **embedding** 模型（生成模型不行）：
   `bge-m3`（中文强，1024 维）或 `nomic-embed-text`（轻，768 维）；确认该模型支持 embeddings 接口。
2. 决定召回形态：默认建议「查询向量 + 同身份 active 节点全量余弦 + 与 FTS 结果合并、过阈值」；
   不做分块（记忆是短条目）、不引入 reranker（现有打分够）、ANN 只在大库时再上。

**恢复步骤（按序，独立 commit）**：
1. **provider 客户端**：`/api/embeddings` 与 `/v1/embeddings` 双兼容；超时≤2s；失败 fail-open（本轮对话不阻塞、留一次日志）。
2. **回填 job**：`vector` handler 从 stub 改为真实现（批量 embed → 写 `embedding` → `vector_state=ready/failed`，
   记录模型名与维度；换模型要能识别并重算）。由 `maintenance` 或手动入队触发，**不自动定时烧算力**。
3. **写入侧**：新节点落库后标 `pending`（异步回填，绝不阻塞写入）。
4. **查询侧**：`search` 里加语义一路（查询向量→同身份 active 余弦→与 FTS 合并进现有预算/阈值）。
5. **面板**：把 `embed` 加回 `SETTINGS_GROUP_ORDER` 与 `groupNodes`，概览加回健康位；`/stats` 加回只统计 pending 的计数。
6. **测试**：假 provider（回填/查询合并/超时/失败）、换模型重算、`vector_state` 状态机。
7. **文档/发布**：MANUAL 术语表、DETAIL 三语、CHANGELOG、架构书 §5.9 补契约；发一个版本。

**工作量**：4–6 小时专注（一版能用）；调优/ANN 另算。
**回退**：把面板组撤出、handler 改回常量 stub、`vector_state` 不回填即可（数据面无破坏）。

### 1.2 语义同义判重（0.8.1-03）
- **是什么**：同义改写（"门禁红了别发" vs "流水线不绿不许上线"）字面 0 相似 → 直接 ADD 重复入库；
  现有 `judge=llm` 只在「最近 12 条候选」内裁决，救不了「候选没找到」。
- **为什么延后**：要么引入模型/embedding（费用+误判丢信息），要么改 Writer 判重契约（停点：需架构书评审）。
- **触发**：线上重复节点率可测地 >2%，或厂长明确要求「不许出现同义重复」。
- **再启动第一步**：先做**免费**的一半——候选发现扩展（`findCandidates` = 最近 N ∪ FTS topK），
  只产 `REVIEW` 候选（reason `paraphrase_suspect`），不做自动 MERGE；付费判重另开 config 默认关。
- **工作量**：免费半 1 天；付费半 2–3 天（含表征测试与费用开关）。
- **回退**：`write.judge=rules` + 候选发现回退为最近 N；候选行可 reject 清理。

### 1.3 FTS `ORDER BY rank` 成本（0.8.1-08 的后半）
- **是什么**：`rank=bm25` 必须对全部命中行算分，`LIMIT 50` 只限返回条数；100k 行全命中同一 trigram 实测 64ms（去 ORDER BY 0.06ms）。
- **为什么延后**：唯一能真正降成本的两条路都动召回语义（时间窗预筛）或改 worker 超时形态，属产品判断。
- **触发**：库 >5 万节点，或单次检索 P95 >200ms，或 worker 1200ms 超时开始频繁重建。
- **再启动第一步**：先用合成 100k 库复测（`scripts/` 下无现成脚本，按审查 P2-14 的 `/tmp/r4perf/bench-fts-rank.mjs` 重建）；
  只做「超时降级返回未排序结果 + 可见标志」，不销毁 worker；时间窗方案需单独评审。
- **工作量**：降级半 1 天；时间窗方案 3 天 + 召回回归。
- **回退**：超时行为回现状（重建线程）。

### 1.5 `sync` 双轨同步 / `backend.mode=http|hybrid`
- **是什么**：与 ai-router 网关的 outbox 同步、外部记忆服务后端（协议 `whale-memory/1`）。
- **为什么延后**：live 零使用（outbox/state 均 0 行），但删除面约 2.3k 行 + 路由/测试广，收益低于回归风险。
- **触发**：厂长确认「不再接网关/不用外部记忆服务」，或这两块开始出 bug 且维护成本高于收益。
- **再启动第一步**：先写删除清单（config 组、routes、transfer 的 sync 段、hybrid backend、面板同步组、三语），再一次性删。
- **工作量**：2–3 天（含全量回归）。
- **回退**：删除即无回退面；删前出 bundle + 库快照。

## 1.8 跨仓：远程吩咐通道（QQ → DSH agent）

- **想要的效果**：不在家时，在 QQ 里说一句（如「转接 DSH：把这个插件版本升一下」），消息进入**带工具/文件能力的
  DSH agent 会话**，干完把结果回帖到 QQ。
- **现状（2026-11-27 实核）**：**这条通路不存在**。
  - QQ 入站（SnowLuma → 网关 3002 → `gateway.py` → Core）走的是微服务对话管线，人设按 source 分：
    QQ 私聊＝阿罗娜、QQ 群＝一叶、DSH 侧＝大肥鱼（`微服务架构全貌与交接指南.md`）；它是**聊天**，不是 agent 干活。
  - `dsh-ai-router-hub` 的 `/api/dsh-chat` 是面板里转发网关 `/api/v1/chat`（同样是聊天管线），不是 DSH 会话。
  - `dsh-ai-router-bridge` 是**记忆桥接**（whale.db ↔ whale-memory 的 JSONL pull/push），不转发对话。
  - T2（`sync`/`hybrid`）只同步记忆条目，与「指挥 DSH」无关。
- **为什么延后**：要新增通路，且安全边界必须先定（远程命令＝把电脑操作权挂到 IM 上）：
  ①只认厂长自己的 QQ 号；②命令白名单/禁止删除与凭据类操作；③全程留痕可撤销；④DSH 必须在跑、网关在线。
- **再启动第一步**：
  1. 查 DSH rc.5 侧有没有可编程入口（HTTP/WS 会话消息注入；当前 checkout 只有安装产物，需要读其暴露接口）；
     没有就先做最小适配（如本地只读/单会话注入服务），不做"全权限远程"。
  2. 在网关/桥侧加「命令识别 + 白名单 + 鉴权 + 队列」，队列必须落库可续跑（铁律 3），失败可见。
  3. 端到端真机：QQ 发命令 → DSH 执行 → 回帖（含拒绝/超时/离线三种态）。
- **工作量**：接口确认 0.5 天；最小通路 2–3 天；安全闸与审计 1 天。
- **回退**：桥侧开关关闭即回现状（QQ 仍只走聊天管线）；DSH 侧无改动可退。
