# 默认铁律（安装自带）

本目录是插件首次安装时随包携带的默认铁律，不是用户数据。

- `rules/`：20 个文件，首次启动一次性播种进 `$DSH_HOME/rules`（已播过就不再播，见 `.seeded.json`）。其中 19 条带编号（1–19 除空号 6、除本地专用 13，另含 21／22／23），另 1 条安全铁律（`iron-rule-safety`，无编号行，`number: 0` 表示不占号）。
- 编号 8、20 已作废（墓碑，`retired/` 有记录），永不复用；下一条新规则从 24 起。
- `iron-rule-8` 的判据已并入 `iron-rule-7`，文件与编号作废（墓碑），不再随包播种；摘要只展示 7。
- `rules-local/`：**不参与默认播种**。`iron-rule-13.md` 仅本机对照组专属工作区生效，其他安装不带过去。

这些都是默认值，用户**可改、可停用（`status: retired`）、可删除**；编号一经占用即保留，删除后不复用。播种只做一次，用户删掉后重启不会复活。

正文口径：每条只答「做什么·何时·怎么判」三问，写可执行约束与机检判据；不写历史由来与理由句、不用模糊词，单篇 ≤500 字。文件内容与真源 `~/.dsh/rules` 逐字一致。
