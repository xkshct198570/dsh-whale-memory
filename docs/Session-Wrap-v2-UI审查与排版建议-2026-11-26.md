# Session Wrap 面板 UI 审查与排版建议（2026-11-26）

> 依据：概览页「会话收尾 / 最近失败」实测截图（2026-11-26 00:26）＋源码 `lib/client-src/50-overview.js`、`99-css.js`、`60-memory.js`（Row 组件）。结论并入 `Session-Wrap-v2-架构书-v1-2026-11-26.md` §7 与 S1 施工。

## 1. 结论

需要优化，但**不是推倒重做**：信息层级、状态语义、空态/失败态与响应式有明确问题；正好并入 v2 S1（收尾卡片重构）一起改，避免二次动工。

## 2. 问题清单（按优先级）

### P1（影响操作/判断）

1. **失败态没有视觉层级**：状态行把“失败”渲染成普通文字（`50-overview.js` wrap 卡 `h('span', null, wrapStateText(...))`），没有颜色/徽标；同页“最近失败”卡（`jobsInfo`）又重复一遍同样的失败，用户看到两处红字却不知道哪个是“当前收尾”。→ 状态行改 `StateBadge`（ok/warn/error 底色）；失败详情只在收尾卡内展开一次，“最近失败”卡折叠为一行计数。
2. **错误码直出**：`latest.error` 原样显示 `bad_json:bad_json`。→ 走 §5.2 错误码→中文一句话映射（“模型输出不是 JSON，已重试 1 次”），原始码放 `title` 供排障。
3. **指标行错位**：4 个 `Row` 塞进 `metaGrid`（`repeat(auto-fit,minmax(180px,1fr))`），`Row` 是 `justify-content:space-between`（`99-css.js:153`），导致每格“标签在左、值贴右”，四格间距不齐、像表格错行（截图即如此）。→ 改 4 个等宽 `StatTile`（标签 11px 上、值 18px 下、左对齐、gap 8），窄屏 2×2。
4. **按钮无上下文、禁用无解释**：`立即收尾` 只发 `{}`（无会话概念）；status 加载/未启用时按钮直接 disabled，无 tooltip。→ v2 加会话下拉（本次“哪段会话”）；禁用时显示原因（加载中/未启用/后端不支持）。

### P1（续）

16. **重试中被当成“别的会话在跑”**：run 失败后 keeper 还在重试，按钮点击返回 `busy_wrap`，卡片文案“已有收尾任务在跑（可能在别的会话）”误导（真机 01:53 截图）。→ `/wrap/status` 暴露 `latest.retrying{attempt,max}`；卡片显示“正在重试 1/4”，按钮禁用并给原因；`busy_wrap` 文案区分“本会话重试中/其他会话在跑”。

### P2（可读性/效率）

5. **空态无引导**：`wrapEmpty` 只有一行字。→ 空态加“还没有收尾记录；空闲时点「立即收尾」”＋（v2）自动开关说明。
6. **失败卡占主视区**：每条失败 2 行（head+error），最多 5 条，长期占据概览中段。→ 折叠：默认显示“最近失败 1 条 · 展开”，展开后每条一行，附“留证清理”入口（需确认，保留审计到记忆/台账）。
7. **报告是裸 `<pre>`**：长文本在面板内滚动，无复制/下载、无结构。→ 报告保留纯文本但加“复制/下载 .md”，并按段（摘要/候选计数/待办/清洁审计）给折叠标题；v2 增 decisions 计数摘要。
8. **卡头溢出风险**：`settingHead` 无 `flexWrap`（`99-css.js:41`），窄屏标题+按钮会挤。→ `flexWrap:'wrap'` + 按钮 `marginLeft:auto`。
9. **页签换行**：六页签 `flexWrap:'wrap'`（`99-css.js:69`）在窄屏会折成两行，sticky 高度跳动。→ 改横向滚动条（`overflowX:auto` + `whiteSpace:nowrap` + 细滚动条），保持单行。
10. **间距不统一**：卡片内 `gap` 在 4/6/8/10/12 混用；`stack` 10、`panel` 12。→ 定 4 的倍数阶梯（4/8/12/16），卡片 padding 12，段落 8。

### P3（打磨）

11. 成功提示只有一行绿字；建议“已排队 run #N · 查看报告”带跳转。
12. 失败/成功时间格式不一（`fmtTime` 与 `updatedAt`）；统一到同一格式并加“多久前”悬浮。
13. 健康 pills 7 个在窄屏挤压（`healthRow` flexWrap 已有，但 pill 文案长）；建议只留 4 个关键项，其余进“更多”。
14. 收尾下拉/勾选需要键盘可达（focus ring）与 aria-label。
15. 深色主题下 `bg-layer-2` 卡片与页面底色对比偏低；建议卡片边框对比 +1 档（token 不变，加 1px 阴影或 inner border）。

## 4. 验收

- 1280×800 与 900×700 两档截图：收尾卡不溢出、指标 4 列/2×2 对齐、页签单行可横滚、失败默认折叠。
- 进行中点击：按钮旁出现中文原因（不是裸码），焦点环可见。
- 空态与首次使用：有引导文案，勾选自动收尾有“会花 token”提示。
- 失败折叠展开后仍能看到原始错误 `title`；清理动作需二次确认。
