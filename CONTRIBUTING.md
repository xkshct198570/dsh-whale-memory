# Contributing

Thanks for helping improve Whale Memory.

## Development

```bash
npm ci
npm test                 # full layered suite
node scripts/check.mjs   # package / manifest / contract gates
node scripts/i18n-check.mjs
node scripts/manual-build.mjs --check
```

The client bundle (`lib/client.js`) is hand-written and checked in. Locale keys live in
`locale/*.json`; the marked block in the client is generated by `scripts/i18n-check.mjs --write`.
The offline manual block is generated by `scripts/manual-build.mjs --write`.

## Rules

- Keep host logic out of client code and domain-specific branches out of main-flow files.
- Every behaviour change needs a regression test that asserts the real payload/DB row, not just HTTP 200.
- Do not commit generated test homes, databases, or credentials.
