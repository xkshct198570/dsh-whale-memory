# 默认铁律（安装自带）

本目录是插件首次安装时随包携带的默认铁律，不是用户数据。

- `rules/`：16 个文件，首次启动一次性播种进 `$DSH_HOME/rules`（已播过就不再播，见 `.seeded.json`）。其中 15 条带编号（1–17，编号 6 为空号、永不复用），另 1 条安全铁律（`iron-rule-safety`，台账里是无编号行，`number: 0` 表示无编号）。
- `rules-local/`：**不参与默认播种**。`iron-rule-13.md` 仅本机对照组专属工作区生效，其他安装不带过去。

这些都是默认值，用户**可改、可停用（`status: retired`）、可删除**；编号一经占用即保留，删除后不复用。播种只做一次，用户删掉后重启不会复活。

正文来源：台账 §2「核心铁律」表（17 行），一行一规则、不合并。铁律正文只写可执行约束与机检判据，不写理由句、不用模糊词，单篇 ≤500 字。
