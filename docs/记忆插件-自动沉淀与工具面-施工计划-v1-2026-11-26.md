## S4 · 反思触发、身份与峰时（1-2 commit）

1. `src/host/reflect-trigger.js`（新 ≤160）：
   - `ctx.on('agent/pre-step')` 维护 `(session,turn,step)`；`tools/result` 把该 step 标记“有非 memory 工具”（排除 `memory_*`、`run_code`、subagent）。
   - turn 变化或 `agent/turn-stopping` 时评估上一 turn 的 distinct step 数；≥7 且该 turn 有工具活动→调 `reflect.scheduleAuto({identity,source:'turn_steps'})`；每 turn 只一次；abort/error 由下一次 pre-step turn 变化评估。
2. `src/core/reflect.js` 四点：
   - keeper handler 改 `(payload)=>run(payload)`；
   - 空闲 tick 与 turn 触发都显式带 `{identity,sessionId,reason}`；
   - `runReflect` 要求 `identity.userId && identity.workspace`，缺→`identity_required` 不回落空三元组；
   - `run()` 不再现取 cfg 身份。
3. `reflect.js` 增 `scheduleAuto({identity,source})`：单一自动闸（`reflect.enabled`、队列已有、日限、`maintenance.suppressWindows` 本地时区）；idle tick 与 turn trigger 共用；手动 `trigger()` 绕过峰时/日限（显式动作），但仍要求身份。
4. `config.js`：`maintenance.suppressWindows`（默认 []，坏值日志 fail-open）；`reflect.enabled` 默认 **false**。
5. reflect 落库走 `backend.write({ingestPolicy:{mode:'auto',minConfidence,confidence:1,dropTaskInstructions:true}, source:'self', origin:'reflect'})`；process 统一闸。
6. `/reflect` 手动路由传 `identityState.lastRecall` 或 top-level identity；无 workspace 返回 `identity_required`。
7. `index.js` 接线 reflect-trigger；`runReflect` 日志 `added/review/rejected` 无正文。

测试：7 步触发/6 步不触发/并行与 PTC 去重/abort 后下一 turn 评估/同 turn 只一次/subagent 不触发；身份 payload 优先/缺失 skip/不写 `''`；峰时自动跳过手动可跑/坏配置；假 LLM 产出 durable active/task REJECT/歧义 CANDIDATE；全量门禁。
